# 弹幕翻译

## 使用方式

FullUI 的“设置 → 翻译与字幕”增加“自动翻译弹幕”。默认关闭，与房间标题开关独立；两者共用目标语言、翻译引擎和用户配置的兼容 AI 接口。iOS／macOS 可用 Apple 原生翻译或大模型，tvOS 使用大模型。

成功时展示译文；不确定语言、相同语言、翻译失败或来不及翻译时保留原文。图片表情、昵称和颜色保持不变，图文消息只翻译文字片段；某个片段未成功时仅保留该片段原文。已显示的历史消息不重新翻译。

大模型只接收需要翻译的文字片段，不附带昵称字段或图片 URL。API Key 继续使用现有本机 Keychain 配置，不进入插件、日志、同步或仓库。开启弹幕翻译可能增加服务用量。

## 接入与生命周期

共享翻译管线位于 `AngelLiveCore/Translation`，每个房间 ViewModel 持有独立的交付队列。三个 FullUI 宿主在原文屏蔽词检查之后接入，译后消息再交给既有聊天列表与飞屏调度器；不修改 transport、插件协议或 ShellUI。

队列按接收顺序交付，每条最多等待 3 秒。最多保留 32 条待交付消息，超出时让最早待处理消息回退原文，防止消息积压。共享翻译请求最多 2 个在途、每秒最多新发起 1 个请求，缓存最多 200 项；重复文本复用缓存或正在进行的工作。超出额度时保留原文，不另建重试队列。上述限制控制客户端请求频率，不代表服务商费用上限。

切房、断连或退出时取消并丢弃未交付工作；进入后台停止新增翻译，恢复前台后处理新收到的消息。旧房间或旧配置的译文不得覆盖当前内容。原生语言资源仍由系统管理，不在原生失败后自动切换付费服务。

接口返回认证错误或服务端限流后，当前配置暂停新弹幕翻译，继续显示原文。修改配置、切换开关或显式点击“测试翻译”可重新尝试；不在弹幕到达时反复重试同一个错误。

## 验证边界

核心测试使用中性合成文本与模拟翻译服务，验证独立开关、图文片段保留、按序交付、超时、队列上限、取消、配置隔离、请求限流和缓存行为。真实服务及 Apple 语言资源的效果需要设备联调，不能由模拟响应或设置页截图代替。

2026-09-29：`swift test --package-path Shared/AngelLiveCore --filter 'RoomTitleTranslationTests|DanmakuTranslationTests'` 最终运行通过 23 项测试（弹幕 9 项、标题回归 14 项），增量构建 2.68 秒，测试 0.179 秒。日志保存在 `/tmp/angellive-danmaku-translation-tests-final.log`。测试包含不响应取消的模拟服务、真实进入在途状态后触发队列溢出、迟到限流错误隔离及显式测试解除暂停；不是实际服务翻译效果证明。

三端修改文件语法解析及 `git diff --check` 通过。全仓扫描覆盖 618 个 UTF-8 文本文件和 85 个二进制文件，仅有已经核对的通用变量／查询示例歧义命中，未发现实际内容平台标识，测试的 `liveType`／`siteId` 无真实编号命中；二进制未做 OCR。
