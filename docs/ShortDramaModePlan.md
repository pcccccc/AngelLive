# 短剧模式与播放页规划

短剧模式围绕同一部剧的连续观看：选剧进入即播放，单集结束自动进入下一集，底部始终提供选集入口。首版先确定 iPhone 竖屏播放体验，沿用 AngelLive 的黑色播放器、白色控制、系统字体、玻璃胶囊和底部渐变。

交互设计预览已经确认，当前实施 iOS FullUI 首版：复用插件分类与搜索选择剧目，接入真实分集及 KSPlayer 视频播放。观看记录持久化、跨端同步及 macOS/tvOS 专用页面留待后续；本次不修改 ShellUI。

## 播放页布局

以 390×844pt 手机布局为设计基准，实际安全区来自系统。视频等比适配，完整保留字幕和画面；其他画幅留黑，不强制裁成竖屏。

顶部为返回和更多，按钮及玻璃背板均为 44pt。更多承载倍速、自动连播等设置，主画面不增加社交操作列。视频等比适配并顶部对齐，下方独立实黑区承载细进度线、17pt 剧名和 12pt 当前集信息，最底部为选集胶囊及其右侧点击循环切速的快捷入口。播放期间保持画面完整，暂停时中央出现播放键，时间仅在暂停或调整进度时显示。

选集与设置使用同一个 SwiftUI 底部模态面板，提供半屏与展开两档。iPhone 面板左右贴边、底部延伸到屏幕边缘，只保留顶部 28pt 连续圆角；内部内容保持 20pt 水平间距与底部安全区。面板使用单层系统 regular Liquid Glass，移除覆盖玻璃的实色背景；内部集数按钮保持普通填充。原生浮动 sheet 在当前 SDK 未提供竖屏横向 inset 清零接口，因此在 FullUI 播放页内实现贴边呈现，不修改全局系统外观。

选集包含约 60×84pt 海报、剧名、可播集数、插件提供的播放范围说明和数字网格。现有房间模型未提供剧情简介，首版不填造简介。390pt 宽采用五列，大字时减少列数并扩展面板高度。集数格仅显示数字，当前集用白色描边、播放标识及无障碍描述共同区分。点击遮罩、关闭按钮、顶部下拖和无障碍 Escape 均走同一关闭流程；播放层在模态面板打开时不响应触摸或无障碍焦点。播放器及其选集、设置面板统一维持深色，适应媒体观看环境。

视觉参考为现有 FullUI 的 `VerticalLiveControllerView.swift`、`UnifiedPlayerControlOverlay.swift`，及 `Common/Constants.swift` 中的播放器遮罩常量；信息密度和选集布局参考用户于 2026年10月8日提供的竖屏播放器截图。正式自动隐藏规则应在设备验收时确定，选集入口始终可达。

参考修订采用满幅电影画面与轻控制：移除首版的剪影、示意对白和三个常驻播放按钮，将暂停操作交给画面点击，将连续切集交给上下滑。选集面板增加海报与剧集信息，保留 AngelLive 的黑白和玻璃材质，不引入参考中的社交计数、付费锁或紫色强调。

## 连播与选集规则

| 操作或状态 | 行为 |
| --- | --- |
| 首次选择一部剧 | 从第一集自动播放 |
| 再次进入一部剧 | 首版从第一可播集开始；持久续看另行实现 |
| 点击画面 | 暂停或继续 |
| 上滑或下滑画面 | 下一集或上一集，仅在同一部剧内切换 |
| 当前集正常结束 | 自动连播开启时播放下一集；关闭时停在当前集结束态 |
| 打开选集 | 暂停播放，记录打开前播放状态 |
| 关闭选集 | 恢复打开前状态 |
| 选择另一集 | 关闭面板，从目标集起点自动播放 |
| 选择当前集 | 关闭面板，保持进度并恢复打开前状态 |
| 首集向前切换 | 保持当前集并提示已是第一集 |
| 最后一集正常结束 | 停在末集结束态，播放键重播本集，保留选集入口，停止自动推进 |
| 切集加载失败 | 保留目标集，提供重试与选集，不悄悄跳过 |
| 没有可播放剧集 | 显示空态和返回操作 |

上下滑手势只作用于视频区域，排除控制按钮、拖动进度和选集面板。提供无障碍上一集、下一集动作。减少动态效果时取消滑动过渡；减少透明度交由系统玻璃材质响应，实际可读性仍需设备验收。

## 首版插件契约

沿用现有 `getCategories`、`getRooms`、`search`、`getPlayback` 和 `refreshPlayback`，不另设内容来源分支。插件 manifest 显式声明：

```json
{
  "hostBehavior": {
    "contentKind": "shortDrama",
    "episodeSelection": "qualityList"
  }
}
```

两个字段均可选；仅以上两个值同时匹配时，iOS FullUI 使用短剧页。缺失、未知声明仍用现有页面，不按名称、录播状态或 URL 推断。路由读取共享 manager 实际选择版本的 manifest，保持 pinned 和 last-good 选择语义。旧端忽略新字段，继续使用原播放菜单。

`qualityList` 表示 `getPlayback` 恰好提供一条非空 CDN，其 `qualitys` 每项是一集。`qn` 为唯一的正集序，宿主升序展示并保留间隙；下一集为返回目录中的下一项。空目录显示空态，多条非空 CDN、重复或非法集序显示契约错误，不截断数据。稳定身份包含插件 ID、房间 ID 和集序，媒体 URL 与标题变化不改变身份。

每项提供有限媒体的 `playbackHints.isLive=false`；播放地址、请求头、解密参数及不透明 `requestContext` 保持现有协议。选择时通过 `RoomPlaybackPreparer` 执行已有 `refreshOnSelect` 行为。原目录项保留刷新声明，刷新结果仅用于本次播放；失败不回退旧集或跳过目标集。

Core 拥有目录解释与结束事件策略；iOS 主 actor 模型拥有解析请求、选择和页面生命周期。切集取消旧请求，以 generation 拒绝迟到结果；每次播放使用新 UUID 和独立 coordinator，以 UUID 拒绝旧层结束回调。仅无错误的 `onFinish` 推进，结束重复事件只消费一次。面板打开时暂存结束事件，关闭后按连播开关处理；离页取消全部待处理工作。

播放器复用 `KSCorePlayerView`、`KSPlayerSessionConfigurator` 和 `KSPlayerPlaybackSession`，每集应用独立 options 与完整请求参数。现有直播恢复协调器不参与短剧续集。首版只声明实际实现的全局能力，不提供后台播放或画中画承诺。

后续独立设计 iPad、macOS 和 tvOS 的浏览与选集布局，并分别验收；不把手机手势直接复制到其他平台。

## 交互修订验收标准

此前验证覆盖播放和静态面板，没有证明拖动跟手、回弹及切换的连续性。以下修订由 Astra 定义，Luna max 实现；构建与设备验收完成前不视为通过。

SwiftUX 已读取 conventions，并仅检索选集底部面板这一组件。目录返回 weak_match、无匹配项，因此按其构建规范复用项目样式，不采用无关组件。视觉沿用现有竖屏直播控制层及已验收的原尺寸贴边玻璃面板。

- 上下拖动只移动实际视频及其黑色画幅，命中层和顶部、底部控制保持固定。拖动期间不重建播放器或解析目标集。识别距离 12pt，纵向超过横向 1.3 倍才锁定；位移达到 `min(120pt, 可拖区域高度 × 18%)`，或至少 28pt 且同方向速度超过 650pt/s 才提交。取消约 0.28s 回弹，提交约 0.22s 退出完成后只切一次；首末边界最多 32pt 阻尼位移。
- 面板和切集手势分别阻塞片尾自动推进，按 OR 聚合。取消在回弹后释放；提交先选择目标集，再释放手势阻塞。换剧按平台与房间身份重建整页模型，旧请求、旧播放器回调及旧动画完成事件不得改写新状态。
- URL 准备与播放器可播放状态分别观察。切集后用当前剧封面暗化及目标集加载反馈衔接，当前 UUID 的缓冲完成后约 0.15s 淡出；不将解析完成或缓冲状态宣称为严格首帧检测。失败停留目标集，保留重试和选集入口。
- 选集与设置面板保留单层系统 regular Liquid Glass、iPhone 全宽贴底和顶部 28pt 圆角。拖柄与标题区下拖时实际面板跟手，80pt 或同向速度 650pt/s 关闭，否则回弹；网格区域只滚动。面板完整关闭后才恢复播放意图。
- 减少动态效果时取消位移和弹簧，使用不超过 0.15s 的淡化。进入后台、旋转、手势取消或离页时清理临时状态；控制目标至少 44pt，窄屏网格相应减少列数。

设备验收须使用最后编辑后的新包，并保存慢拖取消、快甩提交、首末阻尼与面板拖动的录屏。另检查片尾拖动竞争、返回后选择另一部剧、快速选集、失败重试、前后台和旋转。静态截图不能证明动画通过。实际运行结果在验收后另记。

## 面板、倍速与进度修订标准

2026年10月9日用户反馈此前面板存在横向跳动、无法拖动展开或收起，速度选项和进度滑块也需要调整。本轮由 Astra 定义以下标准，Luna max 实现；本节是验收要求，不代表设备已通过。

- 选集、播放设置和快捷倍速共用固定水平位置的面板。面板始终挂载，通过数值高度控制关闭、半屏、展开，移除条件插入的移动 transition。全屏几何只计算一次，不重复叠加安全区；手机全宽，平板宽度最多 560pt。半屏高度为 `min(max(420, H × 0.52), 展开高度)`，展开高度为 `H - safeTop - 12`；辅助功能字号默认展开。
- 拖柄有至少 44pt 的触控区，标题文字及空白可拖动，关闭键和其他按钮独立。12pt、纵横比 1.3 后锁定纵向，双向跟手；半屏上拉展开、展开下拉收至半屏、半屏下拉关闭，一次手势最多一档。跨档阈值为 `min(100, 档位差 × 0.35)`；关闭阈值 80pt；至少 24pt 且同向速度 650pt/s 可提交。短拖取消回原档，滚动内容不改变档位。减少动态效果时即时切换档位，出入场仅短暂淡化。
- 仅完全关闭才释放片尾阻塞并恢复保存的播放意图；展开与收起不重复暂停或改变恢复状态。旋转、后台和取消清理临时手势，保留已提交档位。
