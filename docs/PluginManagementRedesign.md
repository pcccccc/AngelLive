# 插件管理重构验收标准

## 范围与依据

2026-09-18：三端 FullUI 插件管理，包括插件列表、安装/更新状态、订阅源列表、添加订阅源和移除确认。保留现有 manager、consent、批次更新及 App Group 同步语义；ShellUI 入口与共享添加页的默认行为不变。

- 产品依据：`PRODUCT.md` 的原生、克制、沉浸与可预测操作。
- 结构参考：本次 SwiftUX MCP 选择的 [Settings List with Sections](https://www.swiftux.app/uicomponents/settings-list-with-sections)。已读取 component 与 source；采用统一状态行及分组结构，不复制示例的硬编码颜色、字号和数据。
- iOS 视觉参考：系统 inset-grouped List、原生 segmented Picker 和导航工具栏。名称是第一层，版本/登录要求为第二层，行尾为唯一主要操作。
- macOS 视觉参考：原生工具栏、搜索、分段选择、带分隔线的紧凑管理列表和表单 sheet。避免继续把移动端长表单放大。
- tvOS 视觉参考：`TV/AngelLiveTVOS/Source/Setting/SettingView.swift` 的 `menuListView`，以及当天已验收的诊断报告双栏页。普通菜单行在 1920×1080 设备坐标下为 830×66pt，聚焦约 838×74pt，纵向间距 15pt。以最终 hierarchy 实测为准，不能由截图缩放推算。

## iOS / iPadOS

```text
插件管理                         订阅源  ＋
搜索插件
更新状态 / 已安装数量             检查更新
有候选时：全部更新；运行中：进度和当前项目
[ 已安装                         可安装 ]
┌ 图标  插件名称                  更新/安装 ┐
│       版本 / 新版本 · 需登录              │
├ …                                       ┤
└─────────────────────────────────────────┘
```

- 去掉“查看全部”重复弹层，已安装/可安装是同一列表的两个明确范围；搜索作用于当前范围，空搜索结果区别于无插件/无订阅源。
- 普通行图标 44–46pt，内容间距 12pt，名称 body medium，元数据 caption；版本与登录要求位于同一行，间距 6pt，两行间距 4pt。所有操作触控范围至少 44×44pt，以控件实际外框验收，不能给 bordered 按钮的 label 加 44pt 后继续叠加系统内边距。大字号允许操作换行，不用缩小字体塞入行内。
- 行末安装/更新/重试按钮位置稳定，处理中显示文字和进度，等待状态有明确文字。已安装最新不重复堆叠“已安装”标签。
- 卸载在明确菜单/滑动操作中，并显示插件名称和确认；不能把整行轻触直接解释为卸载。
- 订阅源独立导航页。每个源显示主机、地址、健康状态；重试与删除有独立动作，删除确认明确包含关联插件。
- 添加 sheet 只呈现标题、简短说明、地址或兑换码输入、就地错误，以及取消/添加。Return 可提交有效输入；处理中保持文本，避免无意义重复标题。
- iPad 根据可用宽度控制阅读行长，不能使用设备型号判断；窄窗口仍可用。

## macOS

```text
关闭                 插件管理                 订阅源  ＋
更新状态 / 已安装数量               检查更新 / 全部更新
[ 已安装 | 可安装 ]                           搜索插件
─────────────────────────────────────────────────────
图标  名称                                  操作  更多
      版本 · 登录要求
─────────────────────────────────────────────────────
```

- 管理 sheet 建议最小 760×580pt、理想 820×640pt，适应窗口可用尺寸；主体列表可滚动。
- 行图标 36pt，上下内边距各 12pt，普通行目标约 60pt；两行内容垂直间距 4pt：名称 body medium，版本与登录要求共用一行 caption/secondary。异常说明和辅助功能字号可自然增高。按钮使用原生常规尺寸，不使用手机宽胶囊主按钮。
- 保留现有随深浅色模式适配的语义背景；截图中的深色外观本身不是缺陷。管理页读取管理尺寸的图标资源，不放大侧栏专用的迷你图标。已安装范围不重复显示“已安装”。更多菜单仅保留省略号，隐藏附加下拉箭头；操作区与内容按同一行居中对齐，正文宽度不随大窗口无限扩展。
- 保留 ⇧⌘U 全部更新、⇧⌘R 检查更新，新增入口与搜索具有可达的键盘操作；Escape 只关闭当前添加/订阅源 sheet。
- 订阅源管理放独立 sheet，增加、重试、删除都是明确控件；删除/卸载经过具名确认，错误就地保留。
- 不新增全局业务状态，不把窗口的搜索或筛选存进共享 service。

## tvOS

```text
                      插件管理
┌ 左栏（可用宽度 1/2） ─────┬ 右栏（可用宽度 1/2 - 50） ┐
│ 图标 / 当前选中插件名称    │ 检查更新                 ↻ │
│ 版本 / 状态 / 登录要求     │ 全部更新（存在候选/运行中）│
│ 或管理概况与操作说明      │ 订阅源                   › │
│                          │ 已安装                     │
│                          │ 插件名称         状态    › │
│                          │ 可安装                     │
│                          │ 插件名称                 › │
└──────────────────────────┴────────────────────────────┘
```

- 根页使用与设置页一致的安全区、双栏比例和原生默认 Button。右栏统一菜单行，body 字体、15pt 间距；名称在前，状态和图标在后。图标不参与行高计算，禁止用大卡片或额外垂直 padding 改变按钮规格。
- 左栏内容区水平内边距约 90pt，展示当前聚焦插件的信息；普通操作聚焦时展示概况。插件图标约 96pt，标题 title2，说明 callout，长文本可换行。
- 所有插件行 Select 均打开插件详情。详情左侧展示完整名称、版本、登录要求、失败原因；右侧同规格操作行：安装/更新/重试、返回，卸载单独分组并经过确认。最新插件不把 Select 解释为卸载。
- 订阅源行 Select 均打开源详情；源详情提供刷新、返回、删除并卸载关联插件。状态变化不改变行的导航语义。
- 添加源为 FullUI 专用页，左侧说明/已有远程输入二维码，右侧系统 TextField、添加、取消。已有二维码服务契约不变，不修改 ShellUI 复用页。
- 每个子页保持标准根安全区与按钮宽度，可使用独立 `fullScreenCover { NavigationStack { ... } }`，避免 pushed destination 失去横向安全区造成按钮变宽。
- Menu 只关闭当前详情/源列表/输入页一层，返回恢复先前焦点。祖先退出处理不得吞掉子页返回；只在 FullUI 分支隔离修正。
- 更新中的控件保持 identity 与焦点，执行端保留 busy guard；空态有可聚焦的添加入口。右栏滚动预留系统焦点放大区域。

## 状态与验证

- 沿用 `RemotePluginCatalogActionState`、`isWaitingForUpdate`、`PluginUpdateBatch`。保持 installed、install、update、installing、updating、failed、waiting 的区别。
- 全部更新仅更新已安装候选；全部安装仅用于可安装范围，保留 consent。刷新失败与安装失败分别显示，不用“最新”掩盖源异常。
- 加载有明确文字/进度；失败有原因及重试；无源、无安装、无可安装、无搜索结果分别描述。
- 使用系统语义色与字号，尊重深浅色、Dynamic Type、减少动态效果；状态不能只依赖颜色。图标装饰从辅助功能树隐藏，行操作名称含插件名。
- 三端完成最后编辑后重新 MCP BuildProject，并检查 navigator errors；iOS/tvOS 重新 InstallAndRun 后才采集验收截图。Mac 使用已构建新产物运行并原生 UI 验证。
- 验证范围：列表切换/搜索、打开订阅源/添加/取消、错误与空态、卸载/删除确认取消；tvOS 焦点与逐层 Menu 返回、正常/聚焦按钮尺寸。不得用真实插件卸载或用户数据删除充当必要验收步骤。
- 不声称执行了实际下载更新，除非确实有可安全验证的候选与操作证据。最后提供三端真实截图、设备/OS、验证路径和未验证项。
