# Apple 官方 Skills 导出与同步

**触发条件：缺少所需 Apple 官方 Skill、新机器准备或 Xcode 升级同步。** 按根 [AGENTS.md](../../AGENTS.md) 的顺序在相关操作前读取；本流程与根指南同等效力，不能绕过根文件红线。未特别说明的路径均相对仓库根目录。

- 缺少所需 Apple 官方 Skill 时先导出；Xcode 升级后核对并同步。先按根指南 Xcode 版本规则核验工具链，再以命令级 `DEVELOPER_DIR` 查看 `xcrun agent skills export --help`，只用该版本实际支持的参数。
- 先导出到新建临时目录（`--output-dir <临时目录>`），清点 `SKILL.md` 及引用，不混入旧文件。核验技能目录与软链接真实目标，将同名旧目录备份到技能扫描目录之外后，才以 `--output-dir <已确认目录> --replace-existing` 更新。
- 仅更新导出的 Apple Skills，保留客户端软链接，不覆盖 Axiom、自定义技能或其他插件。比较清单、正文、引用及软链接；YAML front matter 按键值语义比较。失败时保留原技能与备份，不以部分输出宣称完成。
- 刷新或重启 Agent 会话，确认新 Skill 列表可发现所需文件；旧会话可能仍缓存旧内容。不假设跨电脑路径相同；导出器连接/启动失败先查版本、进程及权限，不删除隔离属性或修改应用签名绕过检查。导出成功不等于构建或设备验证通过。
- 同步技能不授权修改项目安全设置。
