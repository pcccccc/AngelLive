# 三端短剧观看历史

## 范围与验收约定（2026-10-19，实施中）

FullUI 历史页提供“直播／短剧”切换，页面内选择在播放器返回后保留。短剧使用已有按插件和剧目隔离的逐集进度作为数据来源，补充列表展示信息；不复制播放进度、不改变插件协议或 ShellUI，不引入云同步。

用户明确指定使用房间列表的切换方式，不采用搜索页的分段 Picker。iOS 当前实际入口是 UIKit `PlatformDetailViewController`：复用 `JXSegmentedView` 和分页容器，一级条高 56pt、左右 20pt、项目间距 16pt、原字体缩放与 20×4pt 下划线，支持点击和横向滑动跟手。macOS 用户进一步确认页顶常驻“直播／短剧”两项。初版胶囊与背景横带被用户否定，已由 `gpt-6-astra / high` 接管实际重写：以现有分类行的 13pt 系统字、primary/secondary 层级为参考，改为同字号文字与 20×2pt 短下划线；保留 44×44pt 透明命中区域、项目间距 16pt、水平 20pt 对齐网格，页面背景连续。初版截图不再作为视觉通过证据，修订版待最后编辑后的新包验收。

tvOS 保留现有历史标题与网格，在顶部提供原生“直播／短剧”按钮。焦点与选中状态分开：Select 才切换，切换后焦点停在所选类型，向下进入卡片，空态仍可切换，Menu 沿原返回层级。

清空仅作用于当前类型，确认文案明确范围；删除短剧历史保留逐集续播。旧进度文件保持兼容，无法读取的记录不覆盖。插件不可用时历史仍可见、可删除，播放入口给出明确提示。列表展示、点击和删除使用同一命名空间身份，不能用筛选后的下标操作全量历史。

设计由 `gpt-6-astra / high` 定义，Core 与 iOS/macOS 实现由 `gpt-6.1-sol / high` 承担，tvOS 由 Astra 实现。root 负责接口、独立审查及串行构建／设备验收。SwiftUX 对单个类型切换控件返回 weak_match，使用仓库现有组件。
