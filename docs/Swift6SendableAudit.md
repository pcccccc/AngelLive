# Swift 6 迁移现状与设备验收

文档整理：2026-10-16。代码侧迁移完成于 2026-08-03；当前三端工程使用 Swift 6，Core 使用 tools 6.2 且没有 Swift 5 override。SharedAssets 仍为 tools 5.9 的资源包。

旧警告数量、文件统计、逃生舱清单、迁移中间状态和当时测试结果已移至[历史迁移记录](archive/Swift6SendableAudit20260803.md)。其中“P0 未执行”“当前 Swift 5”等描述仅适用于旧基线，不能作为当前工作区结论。本次只整理文档，没有重新构建或测量并发诊断。

## 仍需真实设备验收

1. 弹幕连接：WebSocket/轮询、断线重连、快速切房、`MainActor.assumeIsolated` 的线程前提及销毁行为。
2. 收藏与书签同步：真实账号两台设备互相增删、远端回调和逐条进度；同步可靠性待办见[同步记录](SyncReliabilityRoadmap.md)。
3. tvOS 弹幕：顶部优先选轨、切字号、在飞弹幕、GIF 与 `MAX_FLOAT_X` 行为。
4. 异步绘制：高密度弹幕下快速取消和清屏，无残影、漏回调，保持 `didDisplay` 语义。
5. tvOS 宿主：二维码同步、网页输入、控制层计时、退出播放检测和 Top Shelf 刷新。

## 维护约束

- JavaScriptCore 对象留在其串行队列，UI 状态回到明确的主 actor。
- 共享包隔离模型变化需要检查所有受影响宿主，不能仅以单端构建替代跨端验证。
- 不为消除诊断直接增加 `@unchecked Sendable`、锁或队列；先确定可变状态所有者和生命周期。
- 历史编译器探针仅适用于当时 SDK；需要调整隔离方式时重新核验当前工具链。
- 后续宿主请求与弹幕并发修复见[2026-10-04 审计记录](archive/HostConcurrencyAudit20261004.md)。其测试范围不自动覆盖之后的代码。
